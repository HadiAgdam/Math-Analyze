# گزارش اعتبارسنجی نسخهٔ اول

- بررسی دیداری همهٔ ۳۶ صفحه از ۷ PDF و ثبت سرفصل‌ها، مثال‌ها و موارد مبهم در material-review.md.
- خروجی نهایی Vite و تولید manifest و Service Worker با موفقیت ساخته شدند؛ ۹۱ دارایی، شامل فونت‌ها و همهٔ جزوه‌ها، در فهرست پیش‌ذخیره هستند.
- ۳۹ آزمون خودکار پاس شدند: محاسبات کسری دقیق، تجزیه و حذف عامل مشترک، قطب‌های زوج و فرد، جهت حد، بی‌نهایت، حدهای بنیادی، نوسان، ورودی‌های نامعتبر، حفظ نقاط تعریف‌نشده و نمایش KaTeX.
- هم‌ارزی تجزیهٔ نمادی پیش از نمایش، با محاسبهٔ چندجمله‌ای دقیق کنترل می‌شود. قالب TeX جداگانه اعتبارسنجی شده است.
- چیدمان دسکتاپ در عرض ۱۴۴۰ و موبایل در عرض‌های ۳۹۰ و ۳۲۰ بررسی شد. در صفحات بررسی‌شدهٔ پیشخوان، درس، فرمول‌ها و نمودار، سرریز افقی صفحه دیده نشد؛ فرمول‌های طولانی در ظرف خود اسکرول می‌شوند.
- جریان واقعی محاسبهٔ مثال (x²−4)/(x−2) با جواب ۴، تجزیهٔ درست صورت، مراحل حل، نمودار نقطهٔ تعریف‌نشده و بزرگ‌نمایی بررسی شد.
- خودآزمایی درس، ثبت خوانده‌شدن، ذخیرهٔ درس و ماندگاری پس از بارگذاری دوباره بررسی شد. تغییرهای آزمایشیِ علامت مطالعه و نشان درس/فرمول بازگردانده شدند.
- جست‌وجوی سراسری فرمول سینوسی، انتقال به فرمول مربوط و نشان‌کردن آن بررسی شد.
- متن‌های شعاری و انگیزشی طبق درخواست کاربر حذف شدند.
- صفحهٔ اصلی، manifest، Service Worker، دو آیکن و هر ۷ PDF از سرور نهایی پاسخ HTTP 200 با نوع محتوای صحیح دادند.
- آزمایش آفلاین: پس از بارگذاری نسخهٔ نهایی روی پورت ۴۱۷۳، فرایند سرور متوقف شد و عدم دسترسی مستقیم به سرور تأیید شد. صفحه در مرورگر با بارگذاری مجدد از کش باز شد؛ محاسبهٔ abs(x)/x در صفر، نتیجهٔ نبود حد دوسویه با حد چپ منفی یک و راست یک را نشان داد و نمودار نیز رسم شد.
- فایل اجرای ویندوز از مسیر Node همراه Codex استفاده می‌کند و به Node سراسری نسخهٔ ۱۶ وابسته نیست. اجرای ابزار راه‌انداز و سروشدن نسخهٔ نهایی بررسی شد.

## حدود بررسی

نصب روی گوشی فیزیکی اندروید انجام نشده است. manifest حالت standalone، زبان فارسی، راست‌به‌چپ و آیکن‌های ۱۹۲ و ۵۱۲ پیکسل دارد. نصب PWA روی گوشی در شبکهٔ محلی به گواهی HTTPS معتبر و مورد اعتماد گوشی نیاز دارد؛ حالت HTTP روی IP فقط برای مشاهده است. راهنمای تنظیم گواهی موجود در README آمده است.

حل‌گر یک سامانهٔ عمومی اثبات یا حل هر نوع حد نیست؛ دامنهٔ محدود و موارد ردشده در رابط و README مشخص‌اند. دارایی‌های وابستگی‌ها و کد تولیدشدهٔ ابزارها ممکن است توضیحات داخلی کتابخانه داشته باشند؛ کد منبع نوشته‌شده برای پروژه فاقد کامنت است.
