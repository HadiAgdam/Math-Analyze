# آنالیز

برنامهٔ محلی فارسی و راست‌به‌چپ برای حد و پیوستگی، با React، JavaScript، Vite، Tailwind CSS، KaTeX، Math.js، Nerdamer و D3.

## اجرا روی این رایانه

فایل `start-analyz.cmd` را اجرا کنید. نسخهٔ ساخته‌شده روی `http://127.0.0.1:4173` باز می‌شود. پنجرهٔ اجرا باید باز بماند؛ با Ctrl+C متوقف می‌شود. اجراکننده ابتدا Node.js همراه Codex را پیدا می‌کند؛ چون نسخهٔ سراسری فعلی این رایانه ۱۶ است و برای Vite جدید کافی نیست. هیچ تغییری در Node سراسری ایجاد نشده است.

برای بازسازی نسخهٔ نهایی:

```powershell
.\start-analyz.cmd --build
```

برای توسعه، روی سیستمی با Node.js نسخهٔ 20.19 یا 22.12 و بالاتر:

```powershell
npm ci
npm run dev
npm test
npm run build
npm run preview
```

پیش‌نمایش توسعه معمولاً روی پورت ۵۱۷۳ و پیش‌نمایش نسخهٔ نهایی روی ۴۱۷۳ است. Service Worker در نسخهٔ نهایی فعال می‌شود؛ در حالت توسعه فعال نیست.

## اندروید و PWA

برای دیدن برنامه در مرورگر اندروید، رایانه و گوشی را به یک شبکه وصل کنید و اجرا کنید:

```powershell
.\start-analyz.cmd --lan
```

سپس آدرس IP رایانه و پورت ۴۱۷۳ را در مرورگر گوشی باز کنید. این حالت HTTP برای مشاهدهٔ برنامه است؛ نصب PWA و Service Worker روی آدرس IP معمولی به HTTPS معتبر نیاز دارند. localhost روی خود رایانه استثنا است و بدون HTTPS اجازهٔ نصب دارد.

برای نصب واقعی PWA روی گوشی در شبکهٔ محلی، باید گواهی HTTPS معتبر و مورد اعتماد گوشی برای نام یا IP سرور داشته باشید. برنامه گواهی‌های موجود را پشتیبانی می‌کند:

```powershell
$env:ANALYZ_HTTPS_CERT = 'C:\certificates\analyz-cert.pem'
$env:ANALYZ_HTTPS_KEY = 'C:\certificates\analyz-key.pem'
.\start-analyz.cmd --lan
```

نشانی HTTPS باید با نام‌های گواهی تطابق داشته باشد. هیچ SDK اندروید، Android Studio، حساب کاربری یا سرویس پولی لازم نیست. روی Chrome اندروید، از منوی مرورگر «نصب برنامه» یا «افزودن به صفحهٔ اصلی» را انتخاب کنید. برنامه تنظیمات اعتماد یا امنیت دستگاه را تغییر نمی‌دهد.

پس از بارگذاری اولیه و تکمیل نصب Service Worker، همهٔ دارایی‌های برنامه، فونت‌ها و ۷ جزوه پیش‌ذخیره می‌شوند. سپس درس‌ها، حل‌گر و نمودار آفلاین کار می‌کنند. اولین بارگذاری و دریافت فایل‌ها باید کامل شود. اطلاعات مطالعه، ذخیره‌شده‌ها و حداکثر ۱۰۰ محاسبهٔ اخیر فقط در localStorage همان مرورگر باقی می‌مانند.

## محتوا

تمام ۷ PDF، مجموعاً ۳۶ صفحهٔ دست‌نویس، به‌صورت دیداری بررسی شده‌اند. گزارش صفحه‌به‌صفحه و ابهام‌ها در [بررسی منابع](docs/material-review.md) قرار دارد. محتوای ساختاریافته در `src/content/course.js` است: ۱۲ درس، ۱۳ فرمول، مثال‌ها و خودآزمایی. فایل‌های مرجع در `public/materials` کپی شده‌اند؛ اصل فایل‌های پوشهٔ والد تغییر نکرده است.

سرفصل‌ها: تعریف حد در فضای متری، معیار دنباله‌ای، اعمال جبری، پیوستگی، تابع توما، معیار تصویر معکوس، فشردگی، اکسترمم، پیوستگی یکنواخت، هاینه–کانتور، همبندی، مقدار میانی، حدهای یک‌طرفه و توابع یکنوا.

مثال‌ها و فرمول‌های محاسباتی اضافه، عنوان «تکمیلی» دارند. موارد مبهم دست‌نویس به استاد نسبت داده نشده‌اند. زمان‌های مطالعه، برآورد رابط برنامه‌اند.

## حل آنالیزی (حالت پیش‌فرض)

صفحهٔ حل تمرین دو حالت مستقل دارد: «حل آنالیزی» و «حل محاسباتی». در حالت آنالیزی، نوع مسئله را «حد» یا «پیوستگی و نوع ناپیوستگی» انتخاب کنید. روش خودکار، گواهیِ معتبرِ موجود را انتخاب می‌کند؛ روش مشخص هم قابل انتخاب است. گزینهٔ بازتعریف f(a) فقط مقدار همان نقطه را تغییر می‌دهد و برای بررسی پیوستگی و نمودار به کار می‌رود.

گواهی‌های ε–δ برای توابع گویا، M–δ برای قطب‌ها، ε–B برای بی‌نهایت، نامساوی و محصورسازی، معیار دنباله‌ای، جزءصحیح و قضیهٔ ترکیب با فرض‌های تأییدشده پیاده شده‌اند. منشأ جزوه‌ای یا تکمیلیِ روش کنار برهان مشخص است. گزارش دقیق معماری، بازخوانی جزوه، فرمولِ گواهی‌ها و محدودیت‌ها در [روش‌های حل آنالیزی](docs/analysis-methods.md) آمده است.

پاسخ محاسباتی هرگز به‌جای برهانِ پیاده‌سازی‌نشده نمایش داده نمی‌شود.

## حل محاسباتی (حالت قبلی)

- توابع گویا با ضرایب عددی، نقطهٔ میل کسری/اعشاری و توان‌های صحیح تا ۱۲: محاسبات کسری با BigInt، استخراج مرتبهٔ صفر، حذف عامل مشترک و بررسی علامت قطب از دو طرف.
- حد در بی‌نهایت برای توابع گویا: مقایسهٔ درجه و ضریب پیشرو.
- ترکیب‌های پیوسته از توابع جبری، sin، cos، exp، log، sqrt و abs در داخل دامنه. در این حالت عدد خروجی تقریبی است.
- حدهای بنیادی sin(kx)/x، (1−cos(kx))/x²، (exp(kx)−1)/x و log(1+kx)/x در صفر، با k عدد ثابت گویا.
- نمونه‌های مشخص abs(x)/x و sin(1/x) یا cos(1/x) در صفر.
- عبارت‌های قطعه‌ای، رادیکال‌های مبهم، پارامترهای نمادی و حالت‌های عمومی خارج از این دامنه صریحاً رد می‌شوند. نمودار یا نمونه‌برداری عددی هرگز مبنای اثبات حد نیستند.

Math.js فقط برای تجزیهٔ ورودی و نمایش ریاضی به کار می‌رود. گره‌های درخت عبارت پیش از استفاده به فهرست مجاز محدود می‌شوند. ارزیابی تابع از مسیر مستقلِ حقیقی انجام می‌شود. تجزیهٔ Nerdamer فقط پس از تطبیق دقیق هم‌ارزی جبری نمایش داده می‌شود. نتایج نامتناهی با توضیح تفاوت حد متناهی مشخص‌اند.

## ساختار

```text
src/content       مدل درس‌ها و فرمول‌ها
src/math          محاسبات مستقل از رابط
src/components    اجزای مشترک و نمودار
src/pages         پیشخوان، آموزش، فرمول‌ها و حل‌گر
src/hooks         ذخیره‌سازی محلی
tests             آزمون‌های درستی ریاضی و KaTeX
docs              بررسی منابع و گزارش اعتبارسنجی
```
